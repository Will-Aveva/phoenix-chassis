# Plan — Chassis Framework Build

*The work plan for building Chassis from the approved specs. Partitioned into atomic, testable Work Units with explicit dependencies.*

---

## Scope

This plan covers the initial build of Chassis: porting the Seek windowing primitives into a standalone Phoenix LiveView layout framework. The build respects:
- **Constitution**: 6 articles (Domain Boundary, Layout Tree, Theming Discipline, Canonical Vocabulary, The Contract, Constitutional Maintenance)
- **Framework Spec**: 35 invariants across 8 sections
- **Adopter Theming Spec**: 15 required CSS custom properties (3 structural, 12 visual)
- **Prompt 01**: Phoenix project creation and port instructions

**Reference implementation** (port from, do not copy blindly):
- `Seek.WorkspaceLayout` (308 lines) → `Chassis.Layout`
- `Seek.WorkspaceManager` (572 lines) → `Chassis.LayoutManager`
- `SeekWeb.Components.Workspace` (143 lines) → `Chassis.Shell`
- `SeekWeb.Components.Sidebar` (170 lines) → `Chassis.Sidebar`
- `SeekWeb.Components.DockPanel` (58 lines) → `Chassis.DockPanel`
- JS hooks: `drag_drop.js`, `tab_hook.js`, `sidebar_item.js`, `drop_target.js`
- CSS: layout-only styles extracted from Seek's `app.css`
